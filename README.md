# PDF RAG Chatbot

## Features
- PDF loading
- Text chunking
- Mistral Embeddings
- Chroma Vector Database
- Retrieval Augmented Generation (RAG)

## Tech Stack
- Python
- LangChain
- ChromaDB
- Mistral AI
- dotenv

## Installation

pip install -r requirements.txt

## Environment Variables

MISTRAL_API_KEY=your_api_key
